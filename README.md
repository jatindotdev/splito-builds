# Splito builds

Android builds of [Splito](https://splito.jatinkumar.dev), made from its
source repository and published as releases here.

[![Newest build](https://img.shields.io/github/v/release/jatindotdev/splito-builds?include_prereleases&sort=date&display_name=release&label=newest%20build&color=6559B3)](https://github.com/jatindotdev/splito-builds/releases)

**[Download from Releases →](https://github.com/jatindotdev/splito-builds/releases)**

- **Releases** (`v1.2.3`) are versions to install. Each has the APK and the
  Play Store AAB.
- **Pre-releases** (`v1.2.3+7`) are builds from the main branch, seven commits
  after 1.2.3. They install over the release they follow, and the next release
  installs over them.

Download the `.apk` from a release and open it on an Android phone to install.
